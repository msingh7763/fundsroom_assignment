================================================================================
                        QUICK START
================================================================================

1. Create Database
   createdb fundsroom

2. Configure Backend
   cd backend
   Create .env file with PostgreSQL credentials
   npm install

3. Seed Database
   npm run seed

4. Configure Frontend
   cd ../frontend
   npm install

5. Start Services
   Terminal 1: cd backend && npm run dev
   Terminal 2: cd frontend && npm run dev

6. Access Application
   Frontend: http://localhost:5173
   Backend: http://localhost:5000/api
   
   Login Credentials:
   • admin@fundsroom.com / Admin@123
   • ops@fundsroom.com / Ops@123
   • sales@fundsroom.com / Sales@123

7. Run Tests
   cd backend && npm test

================================================================================
                        DATABASE SCHEMA
================================================================================

7 Tables with Relationships:

Users (Authentication)
  ├─ id, name, email, password, role, isActive

Locations (Warehouses/Stores)
  ├─ id, name, code, description, isActive
  └─ Unique: (name), (code)

Items (Products)
  ├─ id, name, sku, category, unit, description
  └─ Unique: (sku)

Inventory (Stock Levels)
  ├─ id, itemId, locationId, batch
  ├─ physicalQty, reservedQty
  └─ Unique: (itemId, locationId, batch)

WorkOrders (Tasks)
  ├─ id, workOrderId, locationId, itemId
  ├─ requiredQty, availableQtyAtCreation, shortageQty
  ├─ assignedUserId, status
  └─ Foreign keys: location, item, assignedUser

Transfers (Stock Movements)
  ├─ id, transferId, sourceLocationId, destLocationId
  ├─ itemId, quantity, batch, status
  └─ Foreign keys: sourceLocation, destLocation, item

CustomerOrders (Reservations)
  ├─ id, orderId, customerName, customerEmail
  ├─ itemId, locationId, quantity, status
  └─ Foreign keys: item, location
